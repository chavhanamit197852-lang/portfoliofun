# Amit Chavhan — Magical 3D Portfolio

A cinematic portfolio with an original dark-academia / wizarding-fantasy aesthetic inspired by the supplied forest-train reference image.

## Background video
You said you will provide your own video. Put it here:

    assets/video/portfolio-background.mp4

Optional WebM fallback:

    assets/video/portfolio-background.webm

The HTML already points to both files. The supplied reference image is kept as:

    assets/video/reference-poster.png

It appears automatically if the video has not loaded yet.

## Visual direction
- Deep pine / black cinematic palette
- Warm antique gold and parchment ivory text
- Fog-blue highlights and restrained wine accents
- Full-screen background video behind the interface
- Floating 3D-style orbital emblem
- Glass / metal panels with perspective depth
- Soft mouse-following magical aura
- Gold particle sparks and glyphs around the cursor
- Mouse parallax and card tilt
- Scroll-reveal animation
- Responsive mobile layout
- Reduced-motion support

## Run locally
Use VS Code + Live Server, or any simple local HTTP server.

Example:
    python -m http.server 5500

Then open:
    http://localhost:5500/
